# Code of Conduct

Be decent. Assume the other person is trying to do good work with incomplete
information, because that is usually true.

Concretely, for this project:

- **Bring evidence.** "This is broken" is a start; the command and its output is a
  report. Disagreements about behaviour are settled by running the thing.
- **Say what you did not check.** A finding with its scope stated is more useful
  than one that sounds complete and is not.
- **Correcting someone is fine. Being unpleasant about it is not.** This repository
  documents several of its authors' own mistakes on purpose; nobody here is
  defending an infallible record.

Harassment, personal attacks, and hostility are not welcome and will get you
removed. Report to the address in the commit metadata.
